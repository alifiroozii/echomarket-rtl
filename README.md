# اکومارکت | EchoMarket — Persian Enterprise Marketplace & AI Hub

سامانه یکپارچه و بازار جامع ارزیابی، استعلام قیمت، مقایسه تخصصی و تضمین امانی نرم‌افزارهای سازمانی، زیرساخت ابری و هوش مصنوعی در ایران.

مبتنی بر سیستم طراحی اختصاصی **EchoMarket RTL Design System** استخراج شده از **Google Stitch** (`https://stitch.withgoogle.com/`).

---

## 🚀 ویژگی‌های کلیدی پلتفرم

1. **طراحی راست‌به‌چپ (RTL-First) شرکتی و مدرن:**
   - تایپوگرافی اختصاصی و هماهنگ با فونت وزیری (Vazirmatn) و آیکون‌های Material Symbols Outlined.
   - معماری رنگی سازمانی با تاکید بر تضاد نوری استاندارد (`#004AC6` به عنوان Primary و `#006A61` به عنوان Secondary).
   - طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل.

2. **پایگاه داده ابری بدون سرور (Neon Serverless PostgreSQL):**
   - اتصال مستقیم به پایگاه داده توزیع‌شده Neon در AWS.
   - مدل‌های داده برای محصولات سازمانی (`echomarket_products`)، دسته‌بندی‌ها (`echomarket_categories`)، استعلام‌ها و RFQ (`echomarket_inquiries`)، قراردادهای هوشمند (`echomarket_contracts`) و پرونده‌های حل اختلاف (`echomarket_disputes`).
   - مهاجرت خودکار و بازیابی پایگاه داده از طریق اندپوینت `/api/init-db`.

3. **ویترین و کاتالوگ پویای راهکارها:**
   - صفحه اصلی اختصاصی با معرفی برجسته سامانه مدیریت شیفت **کارجور (KarJoor)**، موتور معاملاتی **تالین (Taline)**، مدل زبانی **آوا (Ava LLM)**، زیرساخت ابری **دیاکو (Diako Cloud)** و درگاه امنیت **کیوان (Qone IAM)**.
   - فیلترهای چندوجهی در صفحه `/explore` بر اساس مدل استقرار (SaaS، On-Premise، هیبرید)، امتیاز کارشناسی، قیمت و دسته‌بندی.

4. **ماتریس مقایسه هوشمند (`/compare`):**
   - مقایسه پهلوبه‌پهلوی دو یا چند راهکار نرم‌افزاری بر اساس تعهدات SLA، پشتیبانی تقویم شمسی، پوشش حساب امانی و قیمت.

5. **صفحات اختصاصی و فرم استعلام بلادرنگ (`/product/[slug]`):**
   - محاسبه‌گر پیش‌فاکتور سازمانی بر اساس تعداد کاربران / صندلی.
   - فرم تعاملی ارسال استعلام (RFQ) و ثبت بلادرنگ در دیتابیس Neon.

6. **ویزارد ثبت محصول ارائه‌دهندگان (`/vendor/register`):**
   - فرم چندمرحله‌ای برای شرکت‌های نرم‌افزاری جهت ثبت محصول و ارسال مستقیم به صف بررسی ادمین.

7. **پیشخوان جامع ارائه‌دهندگان (`/vendor/dashboard`):**
   - کارتابل مدیریت درخواست‌های دمو و استعلام‌ها، مشاهده درآمد موجود در حساب امانی و صدور پیش‌فاکتور رسمی.

8. **کارتابل سازمانی خریدار (`/buyer/portal`):**
   - مشاهده لایسنس‌های نرم‌افزاری فعال، کلیدهای دسترسی، مدیریت آزادسازی وجوه امانی و امکان ارجاع پرونده به هیئت داوری.

9. **میز نظارت کلان و مرکز داوری ادمین (`/admin`):**
   - صف بررسی و تایید محصولات با دکمه تایید یک‌کلیکه و انتشار آنی در کاتالوگ عمومی.
   - پنل داوری و حل اختلاف خریدار و فروشنده با امکان صدور رای نهایی و مختومه کردن پرونده.
   - دفتر کل حساب‌های امانی (Escrow Ledger) جهت رصد تسویه‌های مالی.

## 🛠️ ساختار فنی (Tech Stack)

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Material Symbols + Vazirmatn Font
- **Database:** Neon Serverless PostgreSQL (`pg` connection pool with SSL)
- **Design System Source:** Google Stitch Project (`projects/3994600731962201114`)
- **Deployment:** Vercel Edge Platform

## 📦 نحوه راه‌اندازی محلی

```bash
# نصب پکیج‌ها
npm install

# تنظیم متغیرهای محیطی
cp .env.example .env.local

# اجرای مایگریشن دیتابیس Neon
node scripts/seed-neon.mjs

# اجرای سرور توسعه
npm run dev
```
سرور محلی روی آدرس `http://localhost:3000` در دسترس خواهد بود.
